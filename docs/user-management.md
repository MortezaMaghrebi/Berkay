# مدیریت کاربران

مسیر: پنل مدیریت ← مدیریت کاربران. فقط مدیر دارای نقش دسترسی کامل می‌تواند مشخصات، رمز و نقش دیگران را تغییر دهد.

- بخش مشتریان: جست‌وجو و ویرایش نام، نام خانوادگی، ایمیل، تلفن، وضعیت و رمز حساب فروشگاه.
- بخش مدیران: افزودن مدیر جدید، ویرایش نام و ایمیل، تعیین نقش و فعال یا غیرفعال کردن حساب مدیریت.
- برای دادن دسترسی مدیریت به مشتری، در ویرایش مشتری گزینهٔ ساخت حساب مدیریت را انتخاب کنید، یک نقش و رمز جدید (حداقل ۱۲ کاراکتر با تکرار) وارد کنید. رمز واردشده روی حساب مشتری و حساب مدیریت جدید ذخیره می‌شود. پس از ایجاد، این دو حساب مستقل‌اند.
- اگر مدیر با آن ایمیل وجود داشته باشد، حساب او بازنویسی نمی‌شود؛ از لینک ویرایش حساب مدیریت استفاده کنید.
- خالی گذاشتن هر دو فیلد رمز، رمز فعلی را حفظ می‌کند. رمز فعلی قابل مشاهده نیست.
- آخرین مدیر اصلی فعال قابل غیرفعال‌کردن یا محدودکردن نیست. مدیر نمی‌تواند دسترسی خود را محدود یا غیرفعال کند.
- غیرفعال‌کردن حساب مدیریت، ورود و ویرایش از فروشگاه را نیز متوقف می‌کند. احراز هویت دومرحله‌ای برای ابزار ویرایش فروشگاه هم رعایت می‌شود.

اعتبارسنجی و عملیات ذخیره با تست‌های UserManagementTest و StorefrontEditorTest بررسی شده‌اند. بررسی مرورگر روی لیست و فرم ویرایش و منوی کاربران انجام شده است؛ هیچ رمز یا دسترسی واقعی برای آزمایش تغییر داده نشده است.

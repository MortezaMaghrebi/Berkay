# مجلهٔ تصویری برکای

در پنل، بخش مقالات، هر نوشته فیلد «تصویر شاخص مقاله» و «توضیح تصویر برای خواننده» دارد. فایل افقی JPG، PNG یا WebP تا ۴ مگابایت پذیرفته می‌شود. ویرایش متن بدون انتخاب عکس جدید، عکس فعلی را حفظ می‌کند. اگر تصویری بارگذاری نشده باشد، تصویر موضوعی مجله استفاده می‌شود.

فهرست مطالب از تیترهای h2 متن ساخته می‌شود. برای بخش‌بندی مقاله، از قالب تیتر دوم در ویرایشگر استفاده کنید. زمان مطالعه و مطالب پیشنهادی خودکارند. تصویر در کارت مجله، ابتدای مقاله و متادیتای اشتراک‌گذاری نمایش داده می‌شود.

دو عکس جدید اختصاصی مجله با هوش مصنوعی ساخته شده‌اند؛ تصاویر پیش‌فرض دیگر نیز تصویرسازی نمونهٔ فروشگاه هستند. زیر تصویر پیش‌فرض این موضوع مشخص است. برای نمایش کالای واقعی، عکس اختصاصی همان محصول را جایگزین کنید.

برای استقرار روی سرور دیگر:

1. `php artisan migrate --force`
2. `php artisan storage:link` (اگر پیوند public/storage هنوز وجود ندارد)
3. `php artisan berkay:publish-guides`
4. `php artisan view:clear` و پاک‌کردن کش پاسخ‌ها

نصب محتوا سه راهنمای جدید ایجاد می‌کند. سه متن اولیه تنها وقتی ارتقا می‌یابند که هنوز دقیقاً متن اولیهٔ خودکار باشند؛ نوشته‌ای که مدیر تغییر داده یا تصویر اختصاصی‌اش را تنظیم کرده، بازنویسی نمی‌شود. تصاویر بارگذاری‌شده روی دیسک public ذخیره می‌شوند و باید همراه فایل‌های storage پشتیبان‌گیری شوند.
